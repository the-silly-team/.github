## who we are

we're a small team (well, one person and a shirtless GPU ceo) that builds silly things for the web. our flagship product is **the silly browser** — a desktop app that injects javascript and css into any website via a bookmarklet. visual only, your screen only.

we also built **the silly engine** — a from-scratch browser engine in zig, because zig sounds silly and we are all about silly.
